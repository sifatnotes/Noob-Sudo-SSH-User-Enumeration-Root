## Learning Path

A practical progression through this **CTF lab collection**:

1. Start with **Noob File Trail** to build basic filesystem investigation skills.
2. Continue with **NoobNet User Enum** to understand user enumeration.
3. Explore **Noob SSH Spark** and SSH-related security concepts.
4. Study **Passwd to Root** for password and privilege-related investigation.
5. Work through **Sudo Sleuth** and **Sudo Ladder**.
6. Progress to **Sudo Takeover: Noob to Root**.
7. Finish with the broader Noob root-focused challenges.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Read the objective and understand the scope.
2. Identify the available services, users, and files.
3. Perform authorized enumeration.
4. Analyze permissions, credentials, configurations, or other relevant clues.
5. Document the security weakness or escalation path.
6. Record what defensive control could prevent the issue.
7. Apply the lesson to future ethical hacking and penetration-testing exercises.

Never test security techniques against systems without explicit authorization.
